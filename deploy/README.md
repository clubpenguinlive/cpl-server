# CPL container stack (historical)

This file documented the original containerization bring-up for the dockerized CPL stack: the
four images (`cpl-assets-base`, `cpl-web`, `cpl-php`, `cpl-server`) and how they were built and
promoted. It no longer reflects current practice and is kept only as background.

For how to build and run the server today, see the repo-root [`../DEPLOY.md`](../DEPLOY.md).
